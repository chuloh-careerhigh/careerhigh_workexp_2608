회의비 또는 임차비를 사용했다면 **결제한 날짜를 기준으로 증빙 문서를 한 개씩** 작성합니다. 모든 영수증은 해당 문서에 첨부하고 원본 스캔 파일도 별도로 보관해야 합니다.

## 날짜별 작성 기준

| 해당 날짜의 지출 | 작성할 문서 | 필요한 개수 |
| --- | --- | ---: |
| 식비·다과비 등 회의비 사용 | 회의록 | 해당 날짜에 1개 |
| 임차비 사용 | 검수확인서 | 해당 날짜에 1개 |
| 회의비와 임차비를 모두 사용 | 회의록과 검수확인서 | 각각 1개, 총 2개 |

같은 날짜에 회의비 영수증이 여러 장이어도 회의록은 한 개입니다. 같은 날짜에 임차비 영수증이 여러 장이어도 검수확인서는 한 개입니다.

## 문서 ID

| 문서 | ID 형식 | 예시 |
| --- | --- | --- |
| 회의록 | `MM-{team_id}-{YYYYMMDD}` | `MM-tm-101-20260818` |
| 검수확인서 | `IC-{team_id}-{YYYYMMDD}` | `IC-tm-101-20260818` |

`team_id`는 팀 기본정보에 표시된 값을 사용합니다. 문서 ID는 최종 지출결과 양식에서 자동 생성되도록 반영할 기준입니다. 양식이 배포된 뒤 생성된 값을 지출결과서의 해당 결제 행에 그대로 연결합니다.

<Warning>
  현재 지출결과 양식은 최종 확정 전입니다. 팀명이나 팀번호만으로 ID를 직접 만들지 마세요. 날짜 또는 `team_id`가 다르면 다른 문서로 처리됩니다.
</Warning>

## 회의록을 작성해요

회의록에는 해당 날짜의 회의와 회의비 사용을 확인할 수 있는 내용을 작성합니다.

- 회의 날짜와 시작·종료 시각
- 회의 장소와 주제
- 주요 논의 내용
- 참석자와 참석인원
- 회의 사진과 참석자 확인
- 해당 날짜에 사용한 모든 회의비 영수증

식비와 다과비를 같은 날 모두 사용했다면 영수증을 한 회의록에 함께 첨부합니다.

## 검수확인서를 작성해요

검수확인서에는 해당 날짜의 임차 사용을 확인할 수 있는 내용을 작성합니다.

- 사용 날짜와 시간
- 임차 장소 또는 대상
- 사용 목적
- 실제 이용·검수 내용
- 확인자
- 해당 날짜에 사용한 모든 임차비 영수증

## 모든 영수증을 스캔해요

1. 영수증 한 장 전체가 보이도록 스캔하거나 촬영합니다.
2. 날짜, 가맹점, 세부 품목과 금액을 확대했을 때 읽을 수 있는지 확인합니다.
3. 해당 회의록 또는 검수확인서에 영수증을 첨부합니다.
4. 같은 원본 스캔 파일을 Google Forms에 별도로 업로드할 수 있도록 팀 공용폴더에 보관합니다.

<Warning>
  회의록이나 검수확인서에 영수증을 붙였더라도 원본 스캔 파일 제출이 생략되는 것은 아닙니다. 모든 영수증 원본을 별도로 업로드해야 합니다.
</Warning>

<Accordion title="문서 작성 완료 기준">
  - 회의비 사용일마다 회의록이 1개씩 있음
  - 임차비 사용일마다 검수확인서가 1개씩 있음
  - 같은 날짜에 두 유형을 사용했다면 문서가 2개 있음
  - 문서 ID의 `team_id`와 날짜가 맞음
  - 각 문서에 해당 날짜의 관련 영수증이 모두 첨부됐음
  - 모든 영수증 원본 스캔 파일을 별도로 보관했음
</Accordion>
