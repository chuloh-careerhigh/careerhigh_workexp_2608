지출결과서에는 **승인받은 계획과 실제 사용 내역, 사용 후 잔액, 연결된 증빙 문서**가 모두 나타나야 합니다. 결제한 날마다 바로 기록하면 누락을 줄일 수 있습니다.

<Warning>
  승인받지 않았거나 승인된 날짜·타임존·품목·금액과 다른 지출은 임의로 정상 처리하지 마세요. 차이가 있으면 비고에 적고 커리어하이에 확인합니다.
</Warning>

## 작성할 두 가지

| 구분 | 작성 내용 |
| --- | --- |
| 누적 지출결과서 | 프로그램 시작일부터 현재 주차까지의 모든 실제 지출 |
| 해당 주차 지출결과서 | 제출 대상 주차에 사용한 실제 지출과 주간 합계 |

매주 새 파일을 만들지 않습니다. 팀 공용폴더에 저장한 같은 팀 스프레드시트에 실제 사용 내역을 계속 누적합니다.

## 1. 실제 결제 내역을 입력해요

각 결제 건을 한 행씩 작성합니다.

- 지출일
- 품목과 상세 내용
- 가맹점
- 결제시각과 타임존
- 실제 결제금액
- 증빙 유형과 영수증 파일
- 회의록 ID 또는 검수확인서 ID
- 승인 계획과 다른 내용이 있을 때의 사유

## 2. 증빙 문서 ID를 연결해요

회의비와 임차비를 사용한 날에는 지출 행에 해당 문서 ID를 연결합니다.

| 지출 유형 | 연결할 문서 | ID 형식 |
| --- | --- | --- |
| 식비·다과비 등 회의비 | 회의록 | `MM-{team_id}-{YYYYMMDD}` |
| 임차비 | 검수확인서 | `IC-{team_id}-{YYYYMMDD}` |

예시는 `MM-tm-101-20260818`, `IC-tm-101-20260818`입니다. ID는 최종 지출결과 양식에서 자동 생성되도록 반영할 기준입니다. 양식이 배포된 뒤 자동으로 표시된 값을 그대로 사용하고 임의로 고치지 마세요.

<Warning>
  현재 지출결과 양식은 최종 확정 전입니다. 양식에 ID가 표시되지 않는 상태에서 참가자가 직접 ID를 만들면 안 됩니다.
</Warning>

<Note>
  같은 날짜에 같은 유형의 결제가 여러 건이어도 문서 ID는 하나입니다. 해당 날짜의 관련 영수증을 같은 회의록 또는 검수확인서에 모두 첨부합니다.
</Note>

## 3. 주간 합계와 잔액을 확인해요

해당 주차 지출결과서에서 다음 값을 확인합니다.

- 이번 주 최초잔액
- 이번 주 실제 지출 합계
- 이번 주 최종잔액
- 누적 지출 합계
- 모임통장 거래내역의 실제 잔액

지출결과서의 최종잔액과 모임통장 거래내역의 잔액이 다르면 제출하지 말고 누락·중복 입력부터 확인합니다.

## 4. 세 자료를 대조해요

| 확인 항목 | 지출결과서 | 통장 거래내역 | 영수증 |
| --- | --- | --- | --- |
| 결제 날짜 | 일치 | 일치 | 일치 |
| 결제 금액 | 일치 | 일치 | 일치 |
| 가맹점 | 일치 | 확인 가능 | 확인 가능 |
| 세부 품목 | 상세 작성 | — | 확인 가능 |

금액이나 날짜가 다르면 원인을 확인하고 수정한 뒤 다음 단계로 이동합니다.

<Accordion title="작성 완료 기준">
  - 누적 지출결과서와 해당 주차 지출결과서를 모두 작성했음
  - 각 결제를 한 행씩 기록했음
  - 회의비 행에 회의록 ID를 연결했음
  - 임차비 행에 검수확인서 ID를 연결했음
  - 지출결과서·거래내역·영수증의 날짜와 금액이 일치함
  - 최종잔액과 모임통장 잔액이 일치함
</Accordion>
