## 진행방식

![진행방식](/images/진행방식-2.png "진행방식")

팀활동비를 처음 사용한다면 이 페이지부터 확인하세요. 팀활동비는 **지출품의 → 승인 → 사용 → 지출결과** 네 단계로 운영합니다. 매주 담당자를 정한 뒤, 팀원 전체가 계획과 실제 사용 내역을 함께 확인해야 합니다.

## 먼저 확인하세요

| 항목 | 운영 기준 |
| --- | --- |
| 팀별 총예산 | 180만 원 |
| 주간 사용 한도 | 프로젝트별 20·23·26만 원 (2~7주차 6주 적용) |
| 제출 마감 | 오프라인 미팅 전일 오후 6시 |
| 사용 가능 시점 | 커리어하이의 지출품의 승인 이후 |
| 결제 수단 | 팀 모임통장에 연결된 지정 카드 |

## 활동비 사용 흐름

<Steps>
  <Step title="다음 주 지출계획을 제출해요">
    주간 제출 담당자가 다음 주에 사용할 날짜, 타임존, 품목과 금액을 작성해 **오프라인 미팅 전일 오후 6시까지** 지출품의를 제출합니다.
  </Step>
  <Step title="커리어하이가 계획을 확인해요">
    커리어하이가 사용 목적, 품목별 한도와 주간 한도를 확인합니다. 승인은 하루 이상 걸릴 수 있습니다.
  </Step>
  <Step title="승인된 범위에서 사용해요">
    승인 안내를 받은 뒤 승인된 날짜, 타임존, 품목과 금액 안에서 지정 카드로 결제합니다.
  </Step>
  <Step title="실제 사용 결과를 제출해요">
    사용을 마치면 지출결과서, 통장 거래내역과 영수증으로 실제 사용 내역과 잔액을 증명합니다.
  </Step>
</Steps>

<Warning>
  Google Forms 제출 완료 화면은 접수 확인입니다. 커리어하이의 승인 안내를 받기 전에는 결제하지 마세요.
</Warning>

## 왜 품의와 결과를 나누나요?

지출품의는 **사용하기 전에 계획이 기준에 맞는지 확인하는 문서**이고, 지출결과는 **사용한 뒤 계획과 실제 결제가 일치하는지 증명하는 문서**입니다.

- 품의를 먼저 확인하면 승인되지 않은 품목이나 한도 초과를 결제 전에 막을 수 있습니다.
- 결과를 제출하면 실제 결제일, 가맹점, 금액과 잔액을 다시 확인할 수 있습니다.
- 승인된 계획과 실제 사용 내용이 달라질 경우 결제 전에 커리어하이에 변경 가능 여부를 확인해야 합니다.

## 매주 두 문서를 함께 준비해요

**전주 지출결과를 제출하는 날에 다음 주 지출품의도 함께 제출합니다.**

| 기준 주차 | 제출 자료 | 작성 기준 |
| --- | --- | --- |
| 전주 | 지출결과서와 증빙 | 사용을 마친 실제 내역과 잔액 |
| 다음 주 | 지출품의서 | 앞으로 사용할 계획 |

두 문서의 마감은 모두 **소속 프로젝트 오프라인 미팅 전일 오후 6시**입니다. 정확한 날짜는 프로젝트의 `일정 안내`에서 확인하세요.

## 누가 무엇을 하나요?

| 역할 | 해야 할 일 |
| --- | --- |
| 팀원 전체 | 사용 계획, 실제 지출과 통장 잔액을 함께 확인 |
| 주간 제출 담당자 | 지출품의와 지출결과 파일을 준비해 기한 안에 제출 |
| 커리어하이 | 지출품의를 승인하고 지출결과가 운영 기준에 맞는지 확인 |
| 담당 멘토 | 지출결과가 실제 프로젝트 활동과 연결되는지 확인 |

<Note>
  제출 담당자가 파일을 준비하더라도 제출 내용의 정확성과 잔액을 확인할 책임은 팀원 전체에게 있습니다. 오프라인 미팅 당일 검수와 수정 절차는 [제출서류 검수 절차](/team-activity/expenses/review-process)에서 확인하세요.
</Note>
