지출품의와 지출결과는 검수 주체와 완료 기준이 다릅니다. 팀별 교차검증은 오류를 미리 찾는 절차이며, 커리어하이 또는 담당 멘토의 확인을 대신하지 않습니다.

## 서류별 검수 주체

| 제출서류 | 확인하는 사람 | 확인이 끝난 뒤 |
| --- | --- | --- |
| 지출품의 | 커리어하이 | 승인된 계획에 따라 활동비 사용 가능 |
| 지출결과 | 커리어하이, 담당 멘토 | 사용 내역과 증빙에 문제가 없으면 검수 완료 |

<Warning>
  Google Forms 제출 완료 화면은 승인 또는 검수 완료가 아닙니다. 지출품의는 커리어하이의 승인 안내를 받은 뒤에만 사용할 수 있습니다.
</Warning>

## 지출품의 검수

<Steps>
  <Step title="지출품의를 제출해요">
    제출 담당자가 해당 주차 PDF와 최신 누적 Excel을 오프라인 미팅 전일 오후 6시까지 제출합니다.
  </Step>
  <Step title="커리어하이가 확인해요">
    사용 예정일, 타임존, 품목, 금액, 주간 한도와 파일 구성을 확인합니다.
  </Step>
  <Step title="오류를 수정해요">
    내용이나 파일에 문제가 있으면 제출팀이 안내받은 부분을 수정합니다.
  </Step>
  <Step title="승인 안내를 확인해요">
    커리어하이의 승인 안내를 받은 뒤 승인된 범위에서만 결제합니다.
  </Step>
</Steps>

## 지출결과 검수

<Steps>
  <Step title="지출결과와 증빙을 제출해요">
    지출결과서, 거래내역, 회의록·검수확인서와 영수증 원본을 오프라인 미팅 전일 오후 6시까지 제출합니다.
  </Step>
  <Step title="팀별로 교차검증해요">
    검증 담당팀이 파일 구성, 작성 내용과 증빙 사이의 오류를 먼저 확인합니다.
  </Step>
  <Step title="제출팀이 현장에서 수정해요">
    모든 팀원이 오프라인 미팅 후 오류와 누락을 수정합니다.
  </Step>
  <Step title="커리어하이와 담당 멘토가 확인해요">
    실제 사용 내역, 잔액, 증빙과 프로젝트 활동의 연관성을 확인합니다.
  </Step>
</Steps>

## 각 주체의 책임

| 주체 | 책임 |
| --- | --- |
| 제출팀 | 정확한 내용과 파일을 기한 안에 제출하고 발견된 오류를 수정 |
| 검증 담당팀 | 정해진 확인 항목에 따라 다른 팀의 오류와 누락을 표시 |
| 커리어하이 | 지출품의를 승인하고 지출결과의 운영 기준 충족 여부를 확인 |
| 담당 멘토 | 지출결과가 실제 프로젝트 활동과 연결되는지 확인 |

<Note>
  검증 담당팀이 오류를 찾지 못했더라도 제출팀의 책임은 없어지지 않습니다. 잘못된 내용이나 파일명, 필수 서류 누락은 평가에 반영됩니다.
</Note>
