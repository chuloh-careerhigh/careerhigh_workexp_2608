매주 제출 담당자가 해당 주차 PDF와 최신 누적 Excel을 준비해 **한 번의 Google Forms 응답으로 제출**합니다.

## 제출 링크와 마감

<Card title="2608 지출품의 제출" icon="arrow-up-from-bracket" href="https://docs.google.com/forms/d/e/1FAIpQLSd_g5gkJ8B15IjC9ocgzeagNepu-3mI8ENfsW4Q2b7J8VEeAg/viewform?usp=header">
  해당 주차 PDF와 최신 누적 Excel 파일을 한 번에 제출하세요.
</Card>

제출 마감은 **각 프로젝트 오프라인 미팅 전일 오후 6시**입니다. 승인까지 하루 이상 걸릴 수 있으므로 계획이 정리되면 마감 전에 제출하세요.

## 1. 해당 주차 품의서를 PDF로 출력해요

<Steps>
  <Step title="해당 주차 시트를 열어요">
    `03_지출품의_n주차`를 엽니다.
  </Step>
  <Step title="PDF 범위를 선택해요">
    이름 상자에서 해당 주차의 `PDF_WEEK_n` 범위를 선택합니다.
  </Step>
  <Step title="인쇄 설정을 적용해요">
    **파일 → 인쇄**를 선택하고 인쇄 범위를 **선택된 셀**로 설정합니다. 용지는 **A4**, 방향은 **세로**, 배율은 **페이지에 맞춤**으로 설정합니다.
  </Step>
  <Step title="메모 표시를 해제해요">
    서식 지정에서 **메모 표시**를 해제합니다.
  </Step>
  <Step title="한 페이지 PDF로 저장해요">
    내용이 잘리지 않은 한 페이지인지 확인한 뒤 PDF로 저장합니다.
  </Step>
</Steps>

## 2. 누적 Excel 파일을 내려받아요

팀별 Google Sheets에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)**을 선택합니다. 매주 새 파일을 만들지 않고 같은 팀 시트의 최신 누적 내용을 내려받습니다.

## 3. 파일명을 확인해요

| 파일 | 파일명 형식 |
| --- | --- |
| 해당 주차 PDF | `2026_iM일경험_n주차_프로젝트명_n팀_지출품의.pdf` |
| 누적 Excel | `2026_iM일경험_프로젝트명_n팀_지출품의.xlsx` |

예시는 다음과 같습니다.

- `2026_iM일경험_2주차_법인영업_1팀_지출품의.pdf`
- `2026_iM일경험_법인영업_1팀_지출품의.xlsx`

파일명에 `사본`, `(1)`, `최종`, `진짜최종` 같은 문구를 추가하지 마세요.

## 4. Google Forms에서 한 번에 제출해요

Google Forms의 같은 응답에 다음 두 파일을 모두 첨부합니다.

1. 해당 주차 지출품의서 PDF
2. 최신 누적 지출품의 Excel

두 파일의 프로젝트명, 팀번호와 주차가 맞는지 확인한 뒤 한 번만 제출합니다.

<Warning>
  현재 게시된 Google Forms의 파일 업로드 설정이 이 문서의 PDF 1개·Excel 1개 요구와 일치하는지 운영팀이 최종 점검 중입니다. 수정 완료 안내 전에는 제출하지 마세요.
</Warning>

<Accordion title="제출 완료 기준">
  - 오프라인 미팅 전일 오후 6시 이전임
  - 해당 주차 품의서가 한 페이지 PDF로 출력됐음
  - PDF 내용이 잘리지 않았고 메모가 표시되지 않음
  - 최신 누적 Excel 파일을 내려받았음
  - 두 파일의 파일명 형식을 지켰음
  - PDF의 주차, 프로젝트명과 팀번호가 맞음
  - 두 파일을 같은 Google Forms 응답에 첨부했음
  - 전주 지출결과도 같은 날 제출했음
</Accordion>

<Warning>
  Google Forms 제출 완료 화면은 접수 확인일 뿐 승인 완료가 아닙니다. 커리어하이의 승인 안내를 받은 뒤 사용하세요.
</Warning>

제출한 서류는 [제출 서류 상호검증하기](/team-activity/expenses/cross-check) 절차에 따라 확인합니다. 오류가 있으면 오프라인 미팅 당일 수정하고 최종 확인을 받아야 합니다.
