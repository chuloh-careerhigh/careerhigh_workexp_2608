지출품의는 팀활동비를 사용하기 전에 커리어하이의 승인을 받는 절차입니다. **다음 주 계획을 전주 지출결과와 같은 날 제출하세요.**

## 제출 링크

<Note>
  2608 공식 지출품의 Google Forms는 운영팀이 공지한 링크를 사용하세요. 검색해서 찾은 과거 기수의 링크나 양식은 사용하지 않습니다.
</Note>

## 제출할 파일

지출품의 엑셀 파일 1개를 제출합니다. 파일 안에는 다음 두 내용이 모두 있어야 합니다.

1. **누적 지출품의**
2. **해당 주 지출품의서**

<Note>
  누적 자료와 해당 주 자료를 서로 다른 파일로 나누지 않습니다. 운영팀이 제공한 지출품의 엑셀 안에서 두 내용을 모두 작성합니다.
</Note>

지출품의 마감은 **각 프로젝트 오프라인 미팅 당일 12:00**입니다. 승인까지 하루 이상 걸릴 수 있으므로 마감만 기다리지 말고 계획이 정리되는 대로 제출하세요.

## 해당 주 지출계획에 적을 내용

각 결제 계획을 다음 기준으로 구분해 작성하세요.

- 사용 예정 날짜와 결제 예정 시각
- 해당 타임존
- 사용할 품목
- 상세 내용
- 단위, 수량, 단가
- 비고

한 주의 전체 예상액은 **20만 원 이하**여야 하며, 한 주에 작성할 수 있는 품목은 최대 **7건**입니다.

<Note>
  계획을 작성하기 전에 [활동비 사용원칙](/team-activity/expenses/usage-principles)에서 예산, 품목별 한도, 타임존과 금지 항목을 확인하세요.
</Note>

## 제출 전 확인

- [ ] 누적 지출품의를 최신 상태로 작성했음
- [ ] 해당 주 지출품의서를 작성했음
- [ ] 모든 계획에 주차, 사용 예정일, 결제 예정 시각, 타임존, 품목, 상세, 단위, 수량, 단가를 적었음
- [ ] `02_지출품의_누적`의 검토 상태가 `OK`인지 확인했음
- [ ] 해당 주 지출품의서에서 제출 담당자를 선택했음
- [ ] 타임존별 허용 품목과 1회 결제 원칙을 지켰음
- [ ] 주간 합계가 20만 원 이하임
- [ ] 작성한 품목이 7건 이하임
- [ ] 파일명을 [지출결과 제출](/team-activity/expenses/expense-result)의 파일명 형식에 맞췄음
- [ ] 전주 지출결과도 같은 날 제출했음

<Warning>
  Google Forms 제출 완료 화면은 접수 확인일 뿐 승인 완료가 아닙니다. 커리어하이의 승인 안내를 받은 뒤 사용하세요.
</Warning>
