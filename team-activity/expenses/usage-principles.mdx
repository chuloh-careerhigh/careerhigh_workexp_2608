팀활동비는 프로젝트 수행에 필요한 공동 비용입니다. **커리어하이의 사전 승인을 받은 뒤, 승인된 날짜·타임존·품목·금액 안에서만** 사용할 수 있습니다.

<Warning>
  지출품의를 제출했더라도 승인 안내를 받기 전에는 결제할 수 없습니다. 승인되지 않은 지출은 팀활동비로 인정되지 않습니다.
</Warning>

## 핵심 원칙

1. 팀원 모두가 함께 사용하는 비용만 결제합니다.
2. 모임통장에 연결하고 카드번호를 등록한 **지정 카드만** 사용합니다.
3. 승인된 계획과 실제 결제의 날짜, 타임존, 품목, 금액이 일치해야 합니다.
4. 매주 사용 내역과 통장 잔액을 팀원 전원이 함께 확인합니다.
5. 팀원 전원이 지출결과를 확인한 뒤 정해진 서식에 서명합니다.

## 지급액과 사용 한도

| 항목 | 기준 |
| --- | --- |
| 팀별 총예산 | 180만 원(4인 기준) |
| 지급 방식 | 팀장 명의의 모임통장으로 4주 단위 90만 원씩 2회 지급 |
| 주간 사용 한도 | 20만 원 |
| AI·S/W 사용비 | 8주 합계 20만 원 이내 |

<Warning>
  한 주에 20만 원을 초과하면 초과액을 팀원이 공동 환급해야 하며, 다음 주부터 팀활동비를 사용할 수 없습니다.
</Warning>

## 결제 수단

- 모임통장에 연결된 지정 카드로만 결제합니다.
- 카드 발급 후 운영팀이 안내한 방식으로 카드번호를 등록합니다.
- 계좌이체는 사용할 수 없습니다.
- 개인카드로 먼저 결제한 뒤 팀활동비에서 환급받을 수 없습니다.

## 사용 가능한 품목

| 구분 | 사용처 | 팀 한도 | 1인 한도 |
| --- | --- | ---: | ---: |
| 식비 | 일반음식점 | 6만 원 | 1만 5천 원 |
| 다과 | 카페 등 휴게음식점 | 4만 원 | 1만 원 |
| 임차비 | 스터디카페 | 4만 원 | 1만 원 |
| 기타 | AI·S/W 사용, 인쇄비 등 | 별도 공지 기준 | 별도 공지 기준 |

기타 항목은 커리어하이가 별도로 공지한 주간에만 사용할 수 있습니다. 품목별 한도와 별개로 한 주 전체 사용액은 20만 원을 넘을 수 없습니다.

## 시간대별 사용 가능 품목

| 타임존 | 시간 | 사용할 수 있는 품목 |
| --- | --- | --- |
| Zone 1 오전 회의 | 09:00–11:29 | 다과, 임차비 |
| Zone 2 점심 | 11:30–12:59 | 식비 |
| Zone 3 오후 회의 | 13:00–16:59 | 다과, 임차비 |
| Zone 4 저녁 | 17:00–19:59 | 식비 |
| Zone 5 저녁 회의 | 20:00–21:59 | 다과, 임차비 |

- 각 타임존에서는 지정된 품목으로 **1회만** 결제할 수 있습니다.
- 같은 타임존에서 두 번 결제하면 1건만 인정됩니다.
- 22:00 이후에는 결제할 수 없습니다.

## 사용할 수 없는 결제

아래 결제는 팀활동비로 인정되지 않으며, 사용액은 환급 대상입니다.

- 세부 품목을 확인할 수 없는 영수증으로 결제한 경우
- 영수증에 주류가 포함된 경우
- 같은 식당에서 금액을 나누어 결제한 경우
- 같은 식당에서 당일 연속 또는 이틀 연속으로 쪼개어 결제한 경우
- 팀원 일부만 참여한 비용을 결제한 경우
- 식비를 배달앱으로 결제한 경우
- 다과비로 텀블러 등 물품을 구매한 경우
- 스터디카페를 예약 결제한 경우
- 승인받지 않은 날짜, 타임존, 품목 또는 금액으로 결제한 경우

<Note>
  다과비는 팀 회의를 위한 음식에만 사용할 수 있습니다. 물품 구매에는 사용할 수 없습니다.
</Note>

## 결제 전 확인

- [ ] 커리어하이의 승인 안내를 받았음
- [ ] 승인된 날짜와 타임존이 맞음
- [ ] 승인된 품목과 목적이 맞음
- [ ] 품목별 팀 한도와 1인 한도를 지켰음
- [ ] 이번 주 누적 사용액이 20만 원 이하임
- [ ] 팀원 전원이 함께 사용하는 지출임
- [ ] 모임통장에 연결된 지정 카드를 사용함

승인된 계획과 실제 결제 내용이 달라지면 결제하기 전에 운영팀의 안내를 받으세요.

## 결제 후 확인

1. 영수증에 날짜, 가맹점, 세부 품목, 금액이 모두 보이는지 확인합니다.
2. 영수증 이미지를 글자가 선명하게 보이도록 촬영합니다.
3. 모임통장 거래내역과 영수증 금액을 대조합니다.
4. 지출결과서에 실제 사용 내역을 바로 기록합니다.
5. 매주 사용 내역과 잔액을 팀원 전원이 확인하고 서명합니다.
