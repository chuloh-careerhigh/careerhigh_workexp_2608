팀활동비를 결제하기 전에 **예산, 결제수단, 품목, 사용 시간** 네 가지를 확인해야 합니다. 이 페이지의 기준을 사용하면 계획한 지출이 가능한지 결제 전에 판단할 수 있습니다.

<Note>
  이 문서는 2608 일경험 운영 기준입니다. 이전 기수나 다른 사업에서 허용된 방식은 이번 활동비 사용 기준이 아닙니다.
</Note>

## 결제 전에 네 가지를 확인해요

| 확인 항목 | 기준 |
| --- | --- |
| 예산 | 이번 주 식비·다과·임차비 사용액이 20만 원 이하이고 누적이 140만 원 이하인지 확인 |
| 결제수단 | 모임통장에 연결된 지정 카드인지 확인 |
| 품목 | 승인된 목적에 맞고 결제 1건이 1회 팀 한도 이하인지 확인 |
| 사용 시간 | 승인된 날짜와 타임존에 결제하는지 확인 |

네 가지 기준 중 하나라도 맞지 않으면 결제하지 말고 커리어하이에 먼저 문의하세요.

## 전체 예산 계획

팀활동비는 팀별 **총 180만 원**이며, 세 항목으로 나누어 배정됩니다.

| 예산 항목 | 배정액 | 주간 한도 적용 |
| --- | ---: | --- |
| 식비·다과·임차비 | 140만 원 | 적용 (2~8주차, 주 20만 원) |
| 인쇄비 | 20만 원 | 미적용 |
| AI·S/W 사용료 | 20만 원 | 미적용 |
| 합계 | 180만 원 | — |

**인쇄비와 AI·S/W 사용료는 주간 한도에 포함되지 않습니다.** 두 항목은 커리어하이가 공지한 방식과 범위 안에서만 사용합니다.

## 주간 한도는 2주차부터 적용해요

식비·다과·임차비 배정액 140만 원은 **주간 한도 20만 원 × 7주**입니다.

| 항목 | 기준 |
| --- | --- |
| 적용 주차 | 2주차부터 8주차까지 7주 |
| 주간 한도 | 20만 원 |
| 배정액 | 20만 원 × 7주 = 140만 원 |

1주차는 주간 한도 적용 대상이 아닙니다. 1주차 마감에는 2주차에 사용할 지출품의를 제출합니다.

## 예산과 잔액을 함께 관리해요

| 항목 | 기준 |
| --- | --- |
| 팀별 총예산 | 180만 원 |
| 지급 방식 | 팀장 명의의 모임통장으로 4주 단위 90만 원씩 2회 지급 |
| 주간 사용 한도 | 20만 원 (식비·다과·임차비 기준, 2~8주차) |

팀활동비는 먼저 지급되므로 **지출 내역과 남은 잔액을 함께 관리해야 합니다.** 매주 팀원 전원이 거래내역과 잔액을 확인하고 지출결과서에 서명하세요.

### 왜 팀원 전체가 확인하나요?

활동비는 개인이 아니라 팀에 지급되는 공동 예산입니다. 주간 제출 담당자가 서류를 작성하더라도 팀원 전체가 계획, 실제 결제와 잔액을 확인해야 합니다.

<Warning>
  모임통장 카드를 개인적으로 사용했거나 팀원들이 사용 내역을 확인하지 않은 경우 팀 전체에 공동 책임이 적용될 수 있습니다.
</Warning>

## 지정 카드로만 결제해요

지정 카드를 사용하면 지출결과서, 통장 거래내역과 영수증을 같은 결제 건으로 대조할 수 있습니다.

| 사용할 수 있어요 | 사용할 수 없어요 |
| --- | --- |
| 모임통장에 연결하고 카드번호를 등록한 지정 카드 | 계좌이체 |
| 승인된 계획에 따른 지정 카드 결제 | 개인카드로 먼저 결제한 뒤 환급받기 |

카드 발급 후에는 운영팀이 안내한 방식으로 카드번호를 등록하세요.

## 품목별 한도를 확인해요

품목별 한도는 **결제 한 건에 적용됩니다.** 팀 한도는 4인 기준입니다.

| 구분 | 사용처 | 1회 팀 한도 | 1회 1인 기준 |
| --- | --- | ---: | ---: |
| 식비 | 일반음식점 | 6만 원 | 1만 5천 원 |
| 다과 | 카페 등 휴게음식점 | 4만 원 | 1만 원 |
| 임차비 | 스터디카페 | 4만 원 | 1만 원 |

하루 합계 한도는 없습니다. 총액을 제한하는 기준은 **주간 20만 원** 하나입니다. 하루에 20만 원을 모두 사용해도 됩니다.

타임존을 모두 채우면 하루 24만 원이 되지만, 주간 한도 20만 원이 먼저 걸립니다. 품목별 한도를 지켰더라도 **한 주 합계가 20만 원을 넘을 수 없습니다.**

### 주간 한도에 포함되지 않는 항목

| 구분 | 사용처 | 총 배정액 | 사용 기준 |
| --- | --- | ---: | --- |
| 인쇄비 | 인쇄·출력 | 20만 원 | 커리어하이가 공지한 방식과 범위 |
| AI·S/W 사용료 | AI·소프트웨어 구독·사용 | 20만 원 | 커리어하이가 공지한 방식과 범위 |

두 항목도 **같은 지출품의 시트로 승인받습니다.** 주간 20만 원 한도 계산에서만 제외되며, 커리어하이가 제시한 사용 방식과 범위를 벗어난 결제는 인정되지 않습니다.

## 사용할 수 있는 시간을 확인해요

| 타임존 | 시간 | 사용할 수 있는 품목 |
| --- | --- | --- |
| Zone 1 오전 회의 | 09:00–11:29 | 다과, 임차비 |
| Zone 2 점심 | 11:30–12:59 | 식비 |
| Zone 3 오후 회의 | 13:00–16:59 | 다과, 임차비 |
| Zone 4 저녁 | 17:00–19:59 | 식비 |
| Zone 5 저녁 회의 | 20:00–21:59 | 다과, 임차비 |

<Note>
  각 타임존에서는 지정된 품목으로 한 번만 결제할 수 있습니다. 같은 타임존에서 두 번 결제하면 한 건만 인정되며, 22시 이후 결제는 인정되지 않습니다.
</Note>

## 인정되지 않는 결제를 확인해요

아래 결제는 팀활동비로 인정되지 않으며, 사용액은 환급 대상입니다.

| 유형 | 인정되지 않는 사례 |
| --- | --- |
| 증빙을 확인할 수 없음 | 세부 품목이 보이지 않는 영수증, 영수증 누락 |
| 허용되지 않은 품목 | 주류, 다과비로 구매한 텀블러 등 물품 |
| 한도 회피용 분할결제 | 1회 팀 한도를 넘는 금액을 여러 건으로 나누어 결제 |
| 팀 공동 활동이 아님 | 팀원 일부만 참여한 비용을 결제 |
| 허용되지 않은 결제 방식 | 식비를 배달앱으로 결제, 스터디카페를 예약 결제 |
| 승인 내용과 다름 | 승인받지 않은 날짜, 타임존, 품목 또는 금액으로 결제 |

타임존이 다른 결제를 하루에 여러 건 하는 것은 정상 사용입니다. 금지 대상은 1회 팀 한도를 넘기려고 같은 품목을 나누어 결제하는 경우입니다.

<Warning>
  사용 가능 여부가 애매하면 결제 전에 커리어하이에 문의하세요. 자의적으로 사용하면 환급, 감점 또는 참여 중단 조치가 적용될 수 있습니다.
</Warning>

## 결제 전후에 다시 확인해요

### 결제 전

- [ ] 커리어하이의 승인 안내를 받았음
- [ ] 승인된 날짜와 타임존이 맞음
- [ ] 승인된 품목과 목적이 맞음
- [ ] 결제 1건이 품목별 1회 팀 한도 이하임
- [ ] 이번 주 식비·다과·임차비 누적 사용액이 20만 원 이하임
- [ ] 누적 식비·다과·임차비가 140만 원 이하임
- [ ] 팀원 전원이 함께 사용하는 지출임
- [ ] 모임통장에 연결된 지정 카드를 사용함

승인된 계획과 실제 결제 내용이 달라지면 결제하기 전에 운영팀의 안내를 받으세요.

### 결제 후

1. 영수증에 날짜, 가맹점, 세부 품목, 금액이 모두 보이는지 확인합니다.
2. 영수증 이미지를 글자가 선명하게 보이도록 촬영합니다.
3. 모임통장 거래내역과 영수증 금액을 대조합니다.
4. 지출결과서에 실제 사용 내역을 바로 기록합니다.
5. 매주 사용 내역과 잔액을 팀원 전원이 확인하고 서명합니다.

## 기준을 지키지 않으면 어떻게 되나요?

인정되지 않은 금액은 팀이 환급해야 합니다. 주간 한도를 초과하면 다음 주부터 활동비를 사용할 수 없으며, 제출 오류와 규정 위반은 평가에 반영됩니다. 개인 사용처럼 중대한 위반은 프로그램 참여 중단 사유가 될 수 있습니다.
