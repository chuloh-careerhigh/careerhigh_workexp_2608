---

지출품의와 지출결과 제출이 끝나면 다른 팀과 서류를 교차 확인합니다. **검증 담당팀의 확인, 제출팀의 현장 수정, 커리어하이의 최종 확인**까지 끝나야 검토가 완료됩니다.

## 누가 무엇을 확인하나요

| 역할 | 해야 할 일 |
| --- | --- |
| 제출팀 | 전일 오후 6시까지 제출하고 오류가 있으면 미팅 당일 수정 |
| 검증 담당팀 | 제출 파일과 작성 내용, 문서 ID, 증빙 사이의 오류를 먼저 확인 |
| 커리어하이 | 수정 결과를 확인하고 최종 확정 |

<Note>
  검증 담당팀의 확인은 커리어하이의 최종 확인이나 지출품의 승인을 대신하지 않습니다.
</Note>

## 주차별 검증 방식

| 주차 | 검증 방식 |
| --- | --- |
| 2주차 | 모든 팀이 함께 전체 제출 내용을 확인 |
| 3주차 | 모든 팀이 함께 전체 제출 내용을 확인 |
| 4주차부터 | 1팀부터 시작해 팀 순서대로 검증 담당을 교대 |

4주차부터는 해당 주 검증 담당팀이 다른 팀의 제출 내용을 먼저 확인합니다. 다음 주에는 다음 팀이 검증을 맡는 방식으로 순환합니다.

## 제출부터 퇴근까지

<Steps>
  <Step title="전일 오후 6시까지 제출해요">
    각 팀은 전주 지출결과와 다음 주 지출품의를 오프라인 미팅 전일 오후 6시까지 제출합니다.
  </Step>
  <Step title="검증 담당이 먼저 확인해요">
    2·3주차에는 모든 팀이 함께 확인합니다. 4주차부터는 해당 주 검증 담당팀이 먼저 확인합니다.
  </Step>
  <Step title="오류와 누락을 표시해요">
    제출 파일, 작성 내용, 문서 ID와 증빙 사이에 다른 점이 있으면 제출팀이 확인할 수 있도록 표시합니다.
  </Step>
  <Step title="오프라인 미팅에서 수정해요">
    제출팀의 모든 팀원이 오류를 수정하고 다시 대조합니다.
  </Step>
  <Step title="커리어하이의 최종 확인을 받아요">
    문제가 모두 해결됐다는 최종 확인을 받은 팀부터 검토를 마칩니다.
  </Step>
</Steps>

## 지출품의서 확인

- 주차, 프로젝트명과 팀번호가 맞는지 확인합니다.
- 사용 예정일, 결제 예정 시각과 타임존이 모두 작성됐는지 확인합니다.
- 품목, 상세 내용, 단위, 수량과 단가가 작성됐는지 확인합니다.
- 품목별 한도와 주간 20만 원 한도를 지켰는지 확인합니다.
- 한 주의 품목이 7건 이하인지 확인합니다.
- 커리어하이 승인 전에 결제한 내역이 없는지 확인합니다.

## 지출결과와 증빙 확인

- 누적 지출결과서와 해당 주차 지출결과서가 모두 작성됐는지 확인합니다.
- 지출결과서, 통장 거래내역과 영수증의 날짜·금액·가맹점이 일치하는지 확인합니다.
- 지출결과서의 최종잔액과 모임통장 잔액이 일치하는지 확인합니다.
- 회의비를 사용한 서로 다른 날짜 수와 회의록 수가 같은지 확인합니다.
- 임차비를 사용한 서로 다른 날짜 수와 검수확인서 수가 같은지 확인합니다.
- 회의록 ID와 검수확인서 ID의 `team_id`와 날짜가 지출 행과 일치하는지 확인합니다.
- 각 회의록·검수확인서에 해당 날짜의 관련 영수증이 모두 첨부됐는지 확인합니다.
- 해당 주차의 모든 영수증 원본 스캔이 별도로 제출됐는지 확인합니다.
- 모든 파일이 정해진 파일명 형식을 따르는지 확인합니다.

## 오프라인 미팅 참석 준비

- 모든 팀원이 미팅 종료 후 서류 검토에 참여합니다.
- 미팅 종료 후 **약 30분의 여유 시간**을 확보합니다.
- 수정할 수 있도록 지출품의서, 지출결과서와 증빙 파일을 열 수 있는 상태로 준비합니다.
- 문제를 모두 수정하고 최종 확인을 받기 전에는 퇴근할 수 없습니다.

<Warning>
  서류에 오류가 있는 팀은 감점됩니다. 검증 담당팀이 오류를 발견하지 못했더라도 제출팀의 책임이 없어지는 것은 아닙니다.
</Warning>
