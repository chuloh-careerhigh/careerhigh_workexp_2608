제출서류는 활동비 관리의 정확성과 팀의 운영 책임을 확인하는 평가 자료입니다. **내용이 잘못됐거나 파일명이 틀렸거나 필수 서류가 누락된 경우 해당 제출팀을 감점합니다.**

## 감점되는 항목

| 구분 | 감점 대상 |
| --- | --- |
| 제출 내용 오류 | 프로젝트명, 팀번호, 주차, 날짜, 타임존, 품목, 금액 또는 잔액을 잘못 작성한 경우 |
| 파일명 오류 | 지정된 파일명 형식을 지키지 않거나 `사본`, `최종`, `(1)` 같은 임의 문구를 붙인 경우 |
| 필수 파일 누락 | 지출품의 PDF·Excel 또는 지출결과서·거래내역·영수증 등 필수 파일을 빠뜨린 경우 |
| 증빙 불일치 | 지출결과서, 거래내역과 영수증의 날짜·가맹점·금액이 서로 다른 경우 |
| 추가 문서 누락 | 회의비 사용일의 회의록 또는 임차비 사용일의 검수확인서를 빠뜨린 경우 |
| 영수증 오류 | 영수증이 누락되거나 글자를 확인할 수 없고, 해당 문서와 영수증이 연결되지 않은 경우 |
| 제출 경로 오류 | 과거 기수 양식이나 운영팀이 안내하지 않은 경로로 제출한 경우 |
| 제출기한 미준수 | 오프라인 미팅 전일 오후 6시 이후에 제출한 경우 |
| 수정 미완료 | 미팅 당일 안내받은 오류를 수정하지 않거나 최종 확인을 받지 않은 경우 |

## 제출팀이 최종 책임을 져요

- 매주 제출 담당자가 파일을 준비하더라도 제출 정확성은 팀원 전체가 함께 확인합니다.
- 검증 담당팀이 오류를 발견하지 못했더라도 제출팀의 감점 사유가 없어지지 않습니다.
- 교차검증에서 오류가 발견되면 당일 수정해야 하며, 수정 완료 전에는 검수를 마칠 수 없습니다.
- 제출 전 체크리스트를 통과했더라도 실제 제출 파일이 다르면 제출된 파일을 기준으로 확인합니다.

<Warning>
  파일을 다시 제출하거나 미팅 당일 오류를 수정하더라도 최초 제출에서 발생한 오류와 기한 미준수 기록은 평가에 반영됩니다.
</Warning>

## 제출 전 마지막 확인

- [ ] 프로젝트명, 팀번호와 주차가 맞음
- [ ] 모든 파일이 지정된 파일명을 사용함
- [ ] 지출품의의 계획과 실제 사용 내용이 승인 범위 안에 있음
- [ ] 지출결과서, 거래내역과 영수증이 일치함
- [ ] 사용일별 회의록과 검수확인서가 빠짐없이 있음
- [ ] 모든 영수증 원본을 확인할 수 있음
- [ ] 오프라인 미팅 전일 오후 6시 이전임
