지출품의서는 **다음 주 사용 계획을 승인받기 위한 문서**입니다. 매주 담당자를 정하고 누적 시트에 계획을 입력하면 해당 주차 품의서가 자동으로 만들어집니다.

<Warning>
  한 주의 식비·다과·임차비 품의액은 20만 원을 넘을 수 없습니다. 인쇄비와 AI·S/W 사용료는 이 한도에 포함되지 않습니다. 지출품의를 제출했더라도 커리어하이의 승인 전에는 결제할 수 없습니다.
</Warning>

## 1. 기본정보와 담당자를 확인해요

`01_기본정보`에서 프로젝트, 팀번호, 팀원 정보와 이번 주 제출 담당자를 확인합니다. 내용이 다르면 임의로 바꾸지 말고 커리어하이에 수정 요청을 전달하세요.

## 2. 누적 지출품의를 작성해요

`02_지출품의_누적`에서 다음 항목을 입력합니다.

- 주차
- 사용예정일
- 결제예정시각
- 품목
- 상세 내용
- 단위
- 수량
- 단가
- 비고(필요한 경우)

인쇄비와 AI·S/W 사용료도 같은 누적 시트에 입력해 함께 승인받습니다. `품목`에 인쇄비 또는 AI·S/W 사용료를 구분해 적으면 주간 20만 원 한도 계산에서 제외됩니다.

입력을 마친 뒤 각 행의 `검토` 열이 **OK**인지 확인합니다. `OK`가 아닌 행은 주차별 품의서에 반영되지 않습니다.

한 주의 품의서에는 최대 7건이 출력됩니다. 같은 품목·단위·단가의 반복 내역은 한 건으로 합산됩니다.

## 3. 이번 주 최초잔액을 입력해요

`03_주차별_합산`에서 해당 주차의 다음 두 값을 직접 입력합니다.

1. `지난주 최종 잔액`
2. `이번주 최초 잔액 / 실행비 총액`

**이번 주 최초잔액은 반드시 입력해야 합니다.** 잔액이 비어 있으면 제출 준비 상태가 완료되지 않고 주차별 품의서의 예상 잔액도 계산되지 않습니다.

## 4. 자동 생성된 품의서를 확인해요

해당 주차의 `03_지출품의_n주차`를 엽니다. 누적 시트에 입력한 계획, 품의 금액과 예상 잔액이 자동으로 표시됩니다.

다음 항목을 확인하고 필요한 경우 특이사항과 작성일을 입력합니다.

- 프로젝트명과 팀명
- 실행비 총액과 이번 주 최초잔액
- 품목, 상세, 단위, 수량, 단가와 금액
- 품의 금액과 예상 최종잔액
- 제출 담당자

<Accordion title="작성 완료 기준">
  - 기본정보와 제출 담당자가 맞음
  - 다음 주 사용할 모든 계획을 누적 시트에 입력했음
  - 모든 행의 검토 상태가 `OK`임
  - 주간 식비·다과·임차비 품의액이 20만 원 이하임
  - 인쇄비와 AI·S/W 사용료 품의액이 총 배정액 20만 원 이내임
  - 이번 주 최초잔액을 입력했음
  - 자동 생성된 주차별 품의서의 내용과 금액을 확인했음
</Accordion>
