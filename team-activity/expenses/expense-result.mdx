제출 담당자는 지출결과서와 증빙을 한 번의 Google Forms 응답으로 제출합니다. 제출 마감은 **각 프로젝트 오프라인 미팅 전일 오후 6시**입니다.

## 제출 링크

<Warning>
  2608 지출결과 Google Forms는 아직 생성되지 않았습니다. 링크가 이 페이지에 게시되기 전에는 과거 기수 양식이나 다른 제출 경로를 사용하지 마세요.
</Warning>

## 제출할 파일

| 파일 | 제출 기준 |
| --- | --- |
| 지출결과서 Excel | 누적 지출결과서와 해당 주차 지출결과서를 모두 포함 |
| 통장 거래내역 PDF | 해당 주차 거래와 잔액을 확인할 수 있는 전체 내역 |
| 회의록 PDF | 회의비를 사용한 날짜마다 1개 |
| 검수확인서 PDF | 임차비를 사용한 날짜마다 1개 |
| 영수증 원본 스캔 | 해당 주차의 모든 지출 영수증을 한 장도 빠짐없이 제출 |

<Note>
  회의비나 임차비를 사용하지 않은 주에는 해당 문서를 제출하지 않습니다. 문서가 필요한지는 지출 품목과 사용 날짜를 기준으로 판단합니다.
</Note>

## 문서 개수를 확인해요

다음 세 숫자를 먼저 셉니다.

1. 회의비를 사용한 서로 다른 날짜 수
2. 임차비를 사용한 서로 다른 날짜 수
3. 해당 주차 전체 영수증 수

회의비 사용일 수와 회의록 수가 같아야 합니다. 임차비 사용일 수와 검수확인서 수가 같아야 합니다. 영수증 원본 스캔 수는 실제 영수증 수와 같아야 합니다.

## 파일명 적용 예정안

아래 파일명은 지출결과 Google Forms와 최종 양식을 만들 때 함께 확정할 예정안입니다. 확정 안내 전에는 제출용 최종 기준으로 사용하지 마세요.

| 문서 | 적용 예정 형식 |
| --- | --- |
| 지출결과서 Excel | `2026_iM일경험_n주차_프로젝트명_n팀_지출결과.xlsx` |
| 통장 거래내역 | `2026_iM일경험_n주차_프로젝트명_n팀_통장거래내역.pdf` |
| 회의록 | `2026_iM일경험_n주차_프로젝트명_n팀_회의록_문서ID.pdf` |
| 검수확인서 | `2026_iM일경험_n주차_프로젝트명_n팀_검수확인서_문서ID.pdf` |
| 영수증 원본 | `2026_iM일경험_n주차_프로젝트명_n팀_영수증_YYYYMMDD_01.jpg` |

예시는 다음과 같습니다.

- `2026_iM일경험_2주차_법인영업_1팀_회의록_MM-tm-101-20260818.pdf`
- `2026_iM일경험_2주차_법인영업_1팀_검수확인서_IC-tm-101-20260818.pdf`
- `2026_iM일경험_2주차_법인영업_1팀_영수증_20260818_01.jpg`

파일명에 `사본`, `(1)`, `최종`, `진짜최종`, `수정본` 같은 임의 문구를 붙이지 마세요. 같은 날짜의 영수증이 여러 장이면 마지막 번호만 `01`, `02`, `03` 순서로 바꿉니다.

<Warning>
  지출결과 Google Forms가 게시될 때 이 페이지의 파일명도 최종 확정합니다. 그전에는 예시 파일을 실제 제출 경로에 올리지 마세요.
</Warning>

## 제출 순서

<Steps>
  <Step title="지출결과서와 거래내역을 준비해요">
    지출결과서 Excel과 해당 주차 통장 거래내역 PDF를 내려받습니다.
  </Step>
  <Step title="날짜별 증빙 문서를 준비해요">
    회의비 사용일마다 회의록을, 임차비 사용일마다 검수확인서를 PDF로 저장합니다.
  </Step>
  <Step title="모든 영수증 원본을 준비해요">
    문서에 첨부한 영수증을 포함해 해당 주차의 모든 원본 스캔 파일을 모읍니다.
  </Step>
  <Step title="내용과 파일명을 대조해요">
    프로젝트명, 팀번호, 주차, 날짜, 금액, 문서 ID와 파일명을 확인합니다.
  </Step>
  <Step title="Google Forms로 한 번에 제출해요">
    같은 응답에 필요한 파일을 모두 첨부한 뒤 제출합니다.
  </Step>
  <Step title="다음 주 지출품의를 제출해요">
    같은 날 다음 주에 사용할 활동비 지출품의도 제출합니다.
  </Step>
</Steps>

<Accordion title="제출 완료 기준">
  - 오프라인 미팅 전일 오후 6시 이전임
  - 누적·해당 주차 지출결과서가 모두 작성됐음
  - 지출결과서와 거래내역의 잔액이 일치함
  - 회의비 사용일 수와 회의록 수가 같음
  - 임차비 사용일 수와 검수확인서 수가 같음
  - 각 문서 ID의 `team_id`와 날짜가 맞음
  - 각 회의록·검수확인서에 관련 영수증이 첨부됐음
  - 모든 영수증 원본 스캔을 별도로 첨부했음
  - 모든 파일의 프로젝트명, 팀번호, 주차와 파일명이 맞음
  - 다음 주 지출품의도 같은 날 제출했음
</Accordion>

<Warning>
  Google Forms 제출 완료 화면은 검수 완료가 아닙니다. 제출 서류는 팀별 교차검증을 거친 뒤 커리어하이와 담당 멘토가 확인합니다.
</Warning>
