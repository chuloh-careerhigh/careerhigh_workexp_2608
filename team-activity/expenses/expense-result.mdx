지출결과 제출은 승인받은 계획과 실제 사용 내역이 일치하는지 증명하는 절차입니다. **전주 지출결과를 제출하는 날에 다음 주 지출품의도 함께 제출하세요.**

두 서류의 제출 마감은 **각 프로젝트 오프라인 미팅 전일 오후 6시**입니다.

## 제출 링크

<Note>
  2608 공식 지출결과 Google Forms는 운영팀이 공지한 링크를 사용하세요. 검색해서 찾은 과거 기수의 링크나 양식은 사용하지 않습니다.
</Note>

## 제출할 파일 3종

| 파일 | 필수 내용 |
| --- | --- |
| 지출결과서 엑셀 | 누적 지출결과서와 해당 주 지출결과서 |
| 통장 거래내역 파일 | 해당 주 실제 거래내역을 확인할 수 있는 자료 |
| 영수증 이미지 파일 | 각 지출의 세부 품목, 날짜, 가맹점, 금액을 확인할 수 있는 이미지 |

## 지출결과서 엑셀에 작성할 내용

운영팀이 제공한 지출결과서 엑셀 안에서 다음 내용을 작성합니다.

1. **누적 지출결과서**
2. **해당 주 지출결과서**
3. **회의록** — 회의가 있었던 경우
4. **검수확인서** — 물품 또는 결과물 검수가 있었던 경우

<Note>
  회의록과 검수확인서는 해당하는 경우에만 작성합니다. 해당 여부를 임의로 생략하지 말고 실제 지출 내용과 서식 기준을 확인하세요.
</Note>

## 파일명 작성

운영팀은 제출 파일을 별도로 검수합니다. 검수 전에 참가자가 먼저 정해진 파일명 형식을 지켜야 합니다.

| 문서 | 파일명 형식 |
| --- | --- |
| 지출품의 엑셀 | `[2026_iM일경험]_[주차]_[프로젝트코드]_[팀번호]_지출품의.xlsx` |
| 지출결과서 엑셀 | `[2026_iM일경험]_[주차]_[프로젝트코드]_[팀번호]_활동비정산.xlsx` |

예시는 다음과 같습니다.

- `[2026_iM일경험]_[1주차]_[GLOBAL]_[1팀]_지출품의.xlsx`
- `[2026_iM일경험]_[1주차]_[GLOBAL]_[1팀]_활동비정산.xlsx`

- 대괄호와 밑줄을 포함해 형식을 그대로 사용합니다.
- 프로젝트명 대신 운영팀이 공지한 **프로젝트코드**를 사용합니다.
- `최종`, `진짜최종`, `수정본` 같은 임의 문구를 붙이지 않습니다.
- 통장 거래내역과 영수증 이미지는 공식 Google Form에 표시된 파일명 규칙을 따릅니다.

## 제출 전 대조

각 지출 건을 아래 세 자료에서 같은 순서로 확인하세요.

| 확인 항목 | 지출결과서 | 통장 거래내역 | 영수증 |
| --- | --- | --- | --- |
| 결제 날짜 | 일치 | 일치 | 일치 |
| 결제 금액 | 일치 | 일치 | 일치 |
| 가맹점 | 일치 | 확인 가능 | 확인 가능 |
| 품목 | 상세 작성 | — | 세부 항목 확인 가능 |

금액이나 날짜가 다르면 원인을 확인하고 수정한 뒤 제출하세요.

## 제출 순서

<Steps>
  <Step title="지출결과서 엑셀을 완성해요">
    누적 내역과 해당 주 내역을 작성하고, 해당 시 회의록과 검수확인서를 작성합니다.
  </Step>
  <Step title="거래내역과 영수증을 대조해요">
    모든 지출 건의 날짜, 금액, 가맹점, 품목을 확인합니다.
  </Step>
  <Step title="파일명을 정리해요">
    엑셀은 정해진 형식으로, 통장 거래내역과 영수증 이미지는 공식 Google Form에 표시된 형식으로 맞춥니다.
  </Step>
  <Step title="Google Forms로 제출해요">
    세 종류의 파일이 모두 첨부되었는지 확인한 뒤 제출합니다.
  </Step>
  <Step title="다음 주 지출품의를 제출해요">
    같은 날 다음 주 지출품의 제출도 완료합니다.
  </Step>
  <Step title="상호검증과 최종 확인에 참여해요">
    제출 내용을 서로 확인합니다. 오류가 있으면 오프라인 미팅 당일 수정하고 최종 확인을 받습니다.
  </Step>
</Steps>

## 최종 확인

- [ ] 프로젝트코드와 팀번호가 공지된 표기와 일치함
- [ ] 지출품의의 주차가 다음 주로 작성되어 있음
- [ ] 지출결과의 주차가 사용을 마친 전주로 작성되어 있음
- [ ] 지출품의·지출결과 엑셀의 대괄호와 밑줄 형식을 지켰음
- [ ] 파일을 열었을 때 내용이 정상적으로 보임
- [ ] 누적 지출결과서를 작성했음
- [ ] 해당 주 지출결과서를 작성했음
- [ ] 해당 시 회의록을 작성했음
- [ ] 해당 시 검수확인서를 작성했음
- [ ] 통장 거래내역 파일을 첨부했음
- [ ] 모든 영수증 이미지를 첨부했음
- [ ] 세 자료의 날짜와 금액이 일치함
- [ ] 통장 거래내역과 영수증 파일명은 공식 Google Form의 안내를 따랐음
- [ ] 다음 주 지출품의도 같은 날 제출했음

<Warning>
  오류가 있는 팀은 감점됩니다. 모든 팀원은 오프라인 미팅 종료 후 약 30분의 여유 시간을 확보하세요. 수정과 최종 확인이 끝나기 전에는 퇴근할 수 없습니다.
</Warning>
